# 공개 자료의 범위와 출처

공개 저장소에는 자체 구현, 재현 절차, 한국어 보고서, 직접 계산한 그림, 검증된 FEniCS 기준해 및 완료된 신경망 실행을 수록한다. 진행 중인 작업의 부분 가중치·운영 로그·가상환경은 포함하지 않는다. 결과의 완료 목록과 배포 시점은 `validation/PUBLIC_SNAPSHOT.json`을 기준으로 한다.

## 원문 및 외부 자료

기준 논문의 PDF와 원문 그림 발췌는 공개 저장소에 포함하지 않는다. DOI와 원본 SHA-256은 `docs/SOURCE_PROVENANCE.json`에 보존한다. 저자 공개 데이터와 가중치의 라이선스는 `data/AUTHORS_LICENSE`에 있다. 원문에서 추출한 수치 색 범위와 직접 계산한 결과 그림은 출처를 명시하여 제공한다.

공개 배포 설정에서는 포함된 자료의 SHA-256을 검사하고, 미배포 PDF·발췌 이미지는 `not_distributed_not_verified`로 기록한다. 이 표시는 검증 성공을 뜻하지 않는다. 사용자가 해당 원본을 명세의 상대경로에 배치하면 지정된 SHA-256과 일치해야 한다. 외부 PDF 없이도 FEniCS/PINN 계산, 결과 비교, 노트북 및 현재 보고서의 재생성이 가능하다.

## 스냅샷과 장기 학습

GitHub의 결과는 특정 시점에 검증된 자료이며 원래 컴퓨터의 실시간 대시보드가 아니다. `validation/PUBLIC_SNAPSHOT.json`의 미완료 작업은 복제한 환경에서 실행할 수 있다. 완료된 실행의 모델과, 1M 연속 실행에 필요한 100k 선행 체크포인트를 포함한다. 새로운 학습은 로컬 `results/full_study/`에 저장되며 GitHub에 자동 업로드되지 않는다.

기존 단축 학습 실험과 원문 발췌를 포함한 로컬 비교 문서는 공개본의 주 결과에 포함하지 않는다. 소스 코드에 남아 있는 이전 실험용 명령은 해당 결과를 새로 생성할 때 사용할 수 있다.
