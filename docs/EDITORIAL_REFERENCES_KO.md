# 국문 학술 문서의 서술 및 편집 기준

이 보고서는 연구 목적과 수치 결과의 관계가 드러나는 국문 공학 논문의 서술 방식을 참고하여 작성하였다. 원문의 문장을 전재하거나 학술지 게재 논문으로 표시하지 않았으며, 아래 자료의 수치 결과를 본 연구의 근거로 사용하지 않았다.

## 본 보고서에 적용한 기준

1. 초록은 연구 목적, 방법, 검증된 관측 결과와 현재 범위를 한 문단으로 제시한다.
2. 전문 용어는 최초 등장 시 정의하고, 동시·순차 학습과 연성·강제 경계조건의 의미를 구분한다.
3. 표에는 번호와 제목을 부여하고, 그림에는 비교 기준과 출력 표현을 밝힌다.
4. 수치 결과와 원문의 서술, 재구성을 위해 선택한 조건을 구분한다.
5. 결론은 실제 오차를 요약하고, 단일 시드 및 미완료 실험에 따른 해석 범위를 제시한다.
6. 상세 실행 명세와 전체 성분의 오차는 부록에 보존한다. 자료의 완전성을 위해 학술지의 짧은 분량 제한이나 2단 조판은 그대로 적용하지 않는다.
